# Step 3 — 問題生成

- 生成元: `buildGeneratePrompt()` in `src/prompts/generate.js`
- 対象STEP: 3

## System

```
あなたは英語教育の専門家であり、疑問文産出ドリルの作問者です。
学習者は日本語を読んで瞬発的に英語の疑問文を作る訓練をしています。
指定された STEP（操作）とシーンに沿って、出題用の日本語文と、その模範解答・根拠を生成してください。
必ず有効なJSONのみを返してください。マークダウンや説明文は一切含めないでください。

JSONの厳守ルール（grading-prompt.md と同一）:
- 文字列値はダブルクォートのみ使用（シングルクォート不可）
- nuance/note 内で英文・英単語を引用するときは『』を使い、ダブルクォート(")は使わない
- 末尾カンマ禁止 / 生の改行禁止（必要なら \n）

作問の絶対ルール（取りこぼし厳禁）:
- 1文につき疑問詞は1つ（2つ同時に問わない）
- 糸1（助動詞前置）は3機構を正しく使い分ける：本動詞が be→be前出 / 既存助動詞→それを前出 / 一般動詞で助動詞なし→do/does/did を挿入（be・既存助動詞があるとき do は使わない）
- 主語を問う wh では糸1を起動しない（語順そのまま・時制は本動詞の活用に乗せる）
- 間接疑問では従属節の糸1を解除する（do を消し平叙語順）。疑問詞は節頭に保持
- 複雑な関係詞修飾で疑問文を飾り立てない（瞬発訓練の阻害）

一意性ルール（最重要）:
- 出題日本語は、targetGap で指定した1つのスロットだけが答えになるよう、曖昧さなく書く
- targetGap が when/where/why/how のときは answerSense も固定し、その意味に一意に収束する日本語にする
  （例：why で purpose を狙うなら「何のために」と書き、cause と混ざらないようにする）
```

## User

```
次の条件で疑問文ドリルを 5 問つくってください。

- 対象STEP: 3
- STEP定義:
STEP 3: wh・主語以外を聞く — 糸1 + 糸2。糸: 糸1+糸2。targetGap候補: object / complement / when / where / why / how
- 使用してよいシーン（彩り・話題は固定しない／毎問ランダムに1つ選ぶ）:
【A 生活者共通】道聞き、買い物、寮生活、雑談、教室、空港、レストラン
【B ペルソナ】留学生活、職場、家庭、旅行
【B' ロジカルシンキング】自己と将来、語学学校、キャリア
【C 機能軸（functionTag）】確認する、情報を得る、理由・目的を問う、方法を問う、申し出る、提案する
※ 各問は上記からランダムに sceneTag と functionTag を1つずつ選ぶ。MECE非保証・重複容認。
※ 仮定法系（layer:2）は初版では出題しない。
- 時制は以下の核5時制から各問に割り当てて散らす:
- 現在（do/does）
- 過去（did）
- be（is/are/was/were）
- 未来（will）
- 現在完了（have/has）
- 各問に必ず targetGap を設定。when/where/why/how は answerSense も設定
- STEP4（副詞wh）の問題は answerSentence（模範の答え文）も付ける
- 各問の step は対象STEP集合から1つを割り当てる（総合モードでは完全ランダム）

返却形式（JSONのみ、5要素の配列。各要素のスキーマは以下と同一）:
[
  {
    "id": "...", "step": 0, "sceneTag": "...", "functionTag": "...",
    "jp": "...", "targetGap": "...", "answerSense": null,
    "en": "...", "nuance": "...", "thread": "...", "answerSentence": null,
    "parts": [ { "role": "X|V|Y|Z", "text": "...", "note": "..." } ]
  }
]

nuance ルール:
- 模範解答がなぜその形になるかを 1〜2文で。構造分解・語順・時制（どの助動詞が前に出たか／主語whで糸1を使わない 等）のうち該当点に触れる
- why/how/when/where は answerSense（原因/目的・手段/様態・時点/節 等）にも1語触れる
```
